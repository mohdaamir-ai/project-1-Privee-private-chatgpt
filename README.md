# project-1-Privee-private-chatgpt
Privee is a private, locally hosted ChatGPT alternative powered by Ollama, enabling secure, offline AI conversations with full control over data and model customization


## System Requirements
- **RAM:** Minimum 16GB recommended (8GB might experience timeouts with larger models).
- **Processor:** i5 10th Gen or equivalent.
- **Ollama:** Must be installed and running locally.
